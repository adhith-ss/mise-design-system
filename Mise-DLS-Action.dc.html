Action · 10 components

Action

Controls that commit a change or open a set of choices. One primary action per view. Anything that spends money, changes inventory, or alters a schedule uses a primary button and a confirmation step.

Button

A labelled control that performs an action. The label names the action in the operator's words — "Send order", not "Submit".

Use when Something changes as a result of the click — sending a PO, approving an invoice, saving a shift plan.
Use something else when The click only navigates — use Link. There are three or more related actions — use DropdownMenu or MoreMenu.

Icon Button

A square button carrying only an icon. Every instance needs an accessible label and a tooltip — an unlabelled glyph is a guess.

Use when Space is tight and the action is universally understood — close, filter, expand, copy — or inside a Toolbar or table row.
Use something else when The action is consequential or ambiguous. Approving payment always carries words.

Button Group

Two or more related buttons laid out as one unit. Use it to keep an action and its qualifier together — send now versus schedule — not to line up unrelated actions.

attached · primary + split
spaced · secondary set
Props attached boolean, false — collapses gaps and shares borders.
orientation 'horizontal' | 'vertical', horizontal.
gap 4 | 8 | 12, 8.
size 'sm' | 'md' | 'lg' — applied to every child.
variant — applied to every child unless a child overrides.
Accessibility Renders as a plain container with role="group" and an aria-label naming the set. Split triggers get their own label ("Send options"). Tab moves through children; arrows do not — this is not a radio set.

Toggle Button

A button that stays pressed. Use it for a view or filter that persists — "Show variances only" — never for saving state to the server without a separate commit.

Props & accessibility pressed boolean · defaultPressed boolean · onPressedChange (pressed) => void · size sm | md · variant outline | ghost. Sets aria-pressed; the label never changes with state, only the fill does — a label that flips between "Show" and "Hide" makes the pressed state unreadable to screen readers.

Toggle Button Group

A set of toggles sharing one container. Single-select behaves like a filter switch; multi-select behaves like a set of independent flags.

Props & accessibility value string | string[] · onValueChange · type 'single' | 'multiple' · attached boolean, true · allowEmpty boolean, true. Single-select uses role="radiogroup" with arrow-key movement; multiple keeps individual aria-pressed buttons and Tab movement.

Segmented Control

Switches the view of the content beneath it. Two to four short options that are always visible. It changes what you see, not what is saved.

Use when Toggling a granularity or scope in place — day / week / month, all units / this unit.
Use something else when The options are page-level destinations — that is TabList. Over four options — that is Selector.

Track canvas.raised #F1EFE9, thumb surface #fff + elevation.raised, radius 10 / inner 8. Role tablist when it switches panels, otherwise radiogroup; arrows move, Home and End jump to the ends.

Dropdown Menu

A button that opens a list of actions. Items act immediately; destructive items sit last, below a divider.

Link

Navigation to another place. If the click changes data, it is a Button, whatever it looks like.

Props, tokens, accessibility href string · variant 'inline' | 'standalone' | 'muted' · external boolean · size inherits · as element or router link. Colour herb.600, hover herb.800 with underline; inline links keep the underline on hover so colour is never the only signal. External links announce "opens in a new tab" and set rel="noopener". Link text describes the destination — never "click here".

Toolbar

A horizontal band of controls acting on the content below it. Groups are separated by dividers; overflow collapses into a More Menu rather than wrapping.

14 rows
Props & accessibility orientation 'horizontal' | 'vertical' · density 'compact' | 'default' · collapse boolean, true — moves overflow into a More Menu via useOverflow · label string, required. Role toolbar with one tab stop: arrows move between controls inside it, Tab leaves. Dividers are decorative and hidden from the accessibility tree.
