Feedback & Status

Three questions these components answer: what state is this record in, what just happened, and is the system still working. Severity colour is reserved — a warning colour on a routine label spends attention the real warning needs.

Badge

A short label for a state or a category. Use it only when the value is a distinct state — Approved, Disputed — or a grouping. Dates, counts, and descriptions are plain text.

Use when A record is in one of a known set of states, and the state changes how the operator acts on it.
Use something else when The value is metadata (received Aug 22, 14 lines) — that is Text or MetadataList. A live connection state is a StatusDot.

Banner

A persistent message anchored in the page, about the page. It stays until the condition clears — unlike a Toast, which is about something you just did.

Week 34 closes Friday at 6:00 PMInvoices approved after the cutoff land in week 35.
Two invoices exceed last week's priceReview before the Friday close.
Harbor Produce ordering is offlineOrders are saved as drafts. Nothing has been sent since 6:12 AM.
Period close completeAll 41 invoices reconciled.
Props tone 'info' | 'warning' | 'danger' | 'success' · title string, required · description ReactNode · action ReactNode — one button, never two · dismissible boolean, false · onDismiss · inline boolean, false — drops the fill for use inside a Card.
Accessibility Danger and warning banners use role="alert"; info and success use role="status". A banner that appears after a user action moves focus nowhere — it announces instead. Dismiss buttons carry aria-label="Dismiss" plus the banner title.

Toast

A transient confirmation of something the operator just did, with an undo when the action is reversible. Bottom-right, one at a time, stacked to three at most.

Order sent to Harbor Produce$1,486.10 · delivery Tue 6:00 AM
Credit request saved as a draft
Props · useToast toast({ title, description, tone, action, duration, key }) · tone 'success' | 'warning' | 'danger' | 'neutral' · duration ms, 6000, and 10000 when an action is present · key dedupes repeats · dismiss(key) · placement set once on the provider, 'bottom-end'.
Accessibility Region is role="status" with aria-live="polite"; danger toasts use assertive. Timers pause on hover and on keyboard focus. Any undo also exists on the record itself — a toast is never the only route to reversing an action.

Progress through a known quantity, or an indeterminate band when the total is unknown. Also used for a proportion of a budget.

Skeleton

A placeholder that matches the shape of the content it replaces. Use it where layout is predictable — table rows, metric cards — so nothing jumps when data lands.

metric card
table rows
Props & accessibility shape 'text' | 'block' | 'circle' · width number | string · height number · lines number for multi-line text · animated boolean, true. Base neutral.100 #EFEDE6, shimmer to canvas #F7F6F2. The container carries aria-busy="true" and the skeletons themselves are aria-hidden — one announcement, not fifty.

Status Dot

A live condition attached to an entity — a vendor connection, an agent, a unit. Always paired with a word; a bare dot is decoration.

{{ s.label }} {{ s.note }}
Props & accessibility status 'online' | 'busy' | 'warning' | 'offline' | 'unknown' · label string, required · pulse boolean, false — only for work actively in flight · size 6 | 8. The dot is aria-hidden; the label is the accessible name. Status that changes without a page load lives in an aria-live="polite" region.

Empty State

What a container says when it has nothing in it. Three flavours, and they read differently: nothing yet, nothing matching, or something broke.

No invoices yet Connect a vendor and invoices will appear here as they arrive.
No rows match these filters Disputed + Cedar Dairy + this week returns nothing.
Props & guidance variant 'empty' | 'no-results' | 'error' · title string · description ReactNode · action / secondaryAction ReactNode · icon ReactNode · compact boolean for inline panels. The title states the fact, the description says why, the action is the way out. No illustrations of empty boxes and no apologies. Heading level follows the surrounding page, and the whole block is role="status" when it replaces loaded content.
