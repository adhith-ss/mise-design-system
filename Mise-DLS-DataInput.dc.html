Data Input

All inputs are 40px tall with a 12px radius and share one focus treatment. Validation happens on blur, never on keystroke — an operator typing a case count should not be interrupted at the second digit.

Field

The wrapper every input sits in. It owns the label, the hint, the error, and the wiring between them — no input is placed on a page bare.

Text Area

Several lines — a dispute note, a prep instruction. Grows with content to a cap, then scrolls.

Props & accessibility rows number, 3 · autoResize boolean, true · maxRows number, 10 · maxLength · showCount boolean · resize 'none' | 'vertical'. Enter inserts a newline and never submits the form; the character counter is polite, announced only when the remaining count crosses 10%.

Number Input

Counts and quantities with steppers. This is the most-used input in Mise — case counts on an order line — so the stepper targets are 32px and the value is tabular.

Props & accessibility value number · min / max / step · precision number · format 'integer' | 'currency' | 'percent' · unit string · allowMouseWheel boolean, false — wheel scrolling over a case count has changed real orders. Role spinbutton with valuenow, valuemin, valuemax; Arrow keys step, Shift+Arrow steps by ten, and steppers disable at the bounds rather than clamping silently.

Multi Selector

Several values, shown as removable Tokens in the control. Past four selections the control summarises rather than growing without limit.

Props & accessibility value string[] · maxVisibleTokens number, 4 · summaryLabel (count) => string · selectAll boolean · closeOnSelect boolean, false · creatable boolean. Listbox with aria-multiselectable; Backspace removes the last token, each remove button names its own token, and the live count is announced after each change.

Checkbox Input

Independent yes-or-no choices, and the row-selection control in tables. Indeterminate marks a partial group selection.

Props & accessibility checked boolean · indeterminate boolean · onCheckedChange · label · description · disabled · invalid · size 16 | 18. Native input with the label clickable across its whole width; indeterminate sets aria-checked="mixed". A checkbox never triggers navigation or a save on toggle.

Date Input

A date, a range, or a date and time, typed or picked. Typing is always available — an operator entering last week's invoice should not have to navigate a calendar.

Props & accessibility value Date | [Date, Date] · mode 'date' | 'range' | 'datetime' · min / max · disabledDates predicate — vendor delivery days · timezone · presets — this week, last week, period to date · format. Segmented text entry with arrow-key increments per segment; the calendar is a grid with arrow navigation, and a disabled date explains itself in text rather than only greying out.
