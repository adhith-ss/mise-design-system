# MVP · Pilot archive (0.1.0)

The **MVP** section is a frozen copy of the Mise DLS **0.1.0** component set (tag `mvp-pilot-0.1.0`). Use it to compare the pilot baseline against **Post-MVP** — not for new work.

## What was archived

- Every component and story under `storybook/src/components` at tag `mvp-pilot-0.1.0`
- Copied to `storybook/src/archive/mvp-pilot/`, keeping category folders
- Story titles are prefixed with `MVP/`
- Stories carry tags `archived` and `mvp-pilot`

## Release gating

Archived stories are **not** part of the 0.2.0-rc.1 release gate. `scripts/audit-rendered.mjs` skips any story tagged `archived`.

Use **Post-MVP** for current work. Use **MVP** for reference only.
