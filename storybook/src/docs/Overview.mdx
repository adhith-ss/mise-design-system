# Mise DLS

## 0.2.0-rc.1 · Human-led workspace refresh

A versioned update to the existing restaurant operations library. Operators inspect, compare and approve; Plato prepares and explains. The 0.1.0 baseline remains in repository history and its existing Chromatic build.

## What changed

- **Patterns** — composed workflows (DecisionApproval, ForecastScenario, WeeklySnapshot, ImportWizard, SourcesStatus, MetricCard, DishDetailSheet, SessionHistory, PlatoDrawer) under `storybook/src/patterns/`, each with stories and `.spec.json`.
- **MVP Pilot archive** — frozen 0.1.0 stories under `storybook/src/archive/mvp-pilot/` (Storybook title prefix `MVP Pilot/`; reference only, not release-gated). See [MVP Pilot](?path=/docs/mvp-pilot-overview--docs).

- A 13 px minimum across metadata, fields, tables, charts and feedback.
- Light and dark semantic tokens matched to the refreshed app.
- Basil product icons, pruned to the Mise set: glyphs used in the app plus a small reserve for agent-first flows. Plato uses the approved green, full-plate image; a Basil glyph is never used for agent identity.
- Brand focus border with a contiguous lighter ring.
- Overview, anatomy, properties, accessibility and interactive examples in component docs.
- WCAG 2.2 AA as a release gate, with recorded evidence rather than a blanket compliance badge.

## Guardrails

Concise copy. One primary action per decision area. Page-aware Plato tasks. Source freshness and explicit approval are part of the experience, not optional footnotes. No winking or angry shaking during decisions; celebration follows confirmed saves only.

Use the theme and motion controls in the toolbar to inspect the same component. Evaluate rendered foreground/background pairs in every applicable state. The light focus halo is supplemental: the darker border carries contrast.
