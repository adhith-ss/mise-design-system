# Post-MVP · Refresh (0.2.0-rc.1)

The **Post-MVP** section is the current Mise DLS — workspace refresh tokens, updated primitives, and operator **Patterns** aligned with [mise-refresh](https://mise-refresh.vercel.app).

## What’s here

| Area | Contents |
| --- | --- |
| **Foundations** | Colour, type, spacing, elevation, motion, accessibility |
| **Patterns** | DecisionApproval, ForecastScenario, WeeklySnapshot, ImportWizard, SourcesStatus, MetricCard, DishDetailSheet, SessionHistory, PlatoDrawer |
| **Primitives** | Action → Chat & Agent (live components) |
| **Future Scope** | Marketing / splash experiments |

## How to navigate

1. Start with **Post-MVP** for anything shipping after the MVP pilot.
2. Use **MVP** (below) only to compare against the frozen 0.1.0 baseline.
3. Theme and motion toolbars apply to both sections; archived stories show a reference banner.
