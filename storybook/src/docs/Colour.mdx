# Colour

## Semantic pairs

| Role | Light foreground / background | Dark foreground / background |
| --- | --- | --- |
| Body text | `#272E2A / #FFFFFF` | `#EDF0E8 / #202820` |
| Muted text | `#596354 / #FFFFFF` | `#B6C0B0 / #202820` |
| Primary action | `#FFFFFF / #304B3D` | `#263529 / #DBE8B3` |
| Control boundary | `#788270 / #FFFFFF` | `#829078 / #202820` |
| Focus border | `#1E6B4B / #FFFFFF` | `#74AD8B / #202820` |

## Usage

- Use semantic tokens rather than a fixed light-theme hex in components.
- A subtle divider is not an input boundary. Use `control-border` when the boundary identifies the control.
- At-risk metrics use amber with a visible label. Colour never carries status alone.
- Basil icons use the green palette or inherit a semantic text colour. Berry is excluded.
- Plato and food illustrations are supporting imagery, not labels or approval controls.

## Accessibility

Normal text needs 4.5:1; large text and essential non-text graphics need 3:1 where applicable. The light halo is decorative: the darker focus border provides the identifying edge. Test the composited on-screen colours, including transparency and every interactive state, against [WCAG 2.2](https://www.w3.org/TR/WCAG22/).
