## Marketing & mascot (Plato)

Plato — the agent's animated character — is built directly on `brand/600`.
Nothing here is a separate marketing hue; it's the same green ramp extended
with the tints and shades the product screens never needed, plus the two
colours the character itself introduced.

  <ColorItem

    colors={{ start: '#1E6B4B', end: 'rgba(30, 107, 75, 0.24)' }}
  />
</ColorPalette>

**Icon language — two, on purpose.** Product UI icons (`Icon`, Lucide-based)
draw at 1.5px stroke against a 24px box — about 6% of the glyph. Plato's
strokes run close to double that proportionally (16 units against a ~140-unit
glyph canvas, ≈11%), always round-capped, never filled. That weight is what
makes the character read as a character rather than another toolbar glyph —
it is a *marketing/mascot* icon language, not a replacement for the thin
product one, and the two should never be mixed on the same screen.

## Accent — wine (brand guidelines only)

A true second brand hue — not another green extension. Anchored on a
supplied `#6B1E3E`, which turns out to be an *exact* 180° hue rotation of
`brand/600` with identical saturation and lightness (56.2%, 26.9%): not a
coincidence, so the full ramp below rotates every `brand/*` stop the same
way, S/L untouched — same discipline as the brand ramp's own 300/400/950
extension, nothing picked by eye.

- **Reference only — deliberately not a token.** Unlike `brand/*`,
  `mascot-ink`, and `brand-glow`, this ramp has no `--mise-accent-*` entry
  in `tokens.css` and no Tailwind utility. It exists so the hex values are
  documented and consistent wherever a designer needs them by hand — a
  slide, a print piece, a campaign asset — never so a component can pull
  `bg-accent-600` into product UI. If it's ever needed *in the app*, that's
  a deliberate follow-up decision, not something this page grants on its own.
- **Hue distance from `danger`:** accent/600 sits at H≈335°, `danger` at
  H≈4° — about 28-33° apart on the wheel. Distinct, but both read
  "warm/reddish" at a glance. Never pair accent with a status colour in the
  same view.
- **Contrast:** accent/600 is 11.17:1 on white, 10.33:1 on canvas — clears
  AAA (7:1) with room to spare if it's ever used as text.

## Rules

- `brand/600` is the only fill for a primary action. `brand/700` is its hover.
- Amber (`warn`) means *a person must decide*. It appears on Inline Approval and
  on any tool call that writes. Nowhere else.
- `alert` (#B4531B) marks a variance in a number — a short count, a price gap.
  It is a data colour, not a status colour, and never used on a control.
- Never carry meaning in colour alone. Every status in the system has a text label.
