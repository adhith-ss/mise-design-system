# Colour

Two backgrounds, one accent, and status colours that only appear when something
needs attention. A screen full of colour is a screen the operator cannot scan.

## Rules

- `brand/600` is the only fill for a primary action. `brand/700` is its hover.
- Amber (`warn`) means *a person must decide*. It appears on Inline Approval and
  on any tool call that writes. Nowhere else.
- `alert` (#B4531B) marks a variance in a number — a short count, a price gap.
  It is a data colour, not a status colour, and never used on a control.
- Never carry meaning in colour alone. Every status in the system has a text label.
