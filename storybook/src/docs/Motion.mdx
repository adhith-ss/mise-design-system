# Motion

Motion confirms a change; it never introduces one. Two durations and one easing
curve cover the whole system.

| Token | Value | Use |
| --- | --- | --- |
| duration-fast | 120ms | Hover, focus, colour changes |
| duration-base | 180ms | Enter and exit, expand and collapse |
| ease | `cubic-bezier(.2,0,.2,1)` | Everything |

## Rules

- Nothing animates position on load. Streaming text arrives in its final layout.
- The streaming caret is the only looping animation in the system, and it is
  hidden under `prefers-reduced-motion`.
- Under `prefers-reduced-motion` both durations collapse to 1ms in
  `tokens.css` — components need no extra handling.
- No spinners for anything nameable. If it takes over two seconds, it gets an
  `AgentStatus` step with a label the operator would use.
