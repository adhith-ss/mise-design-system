# Type

Manrope for the interface and numeric values. Use tabular numerals for amounts and comparisons; monospace is reserved for literal code.

<Typeset fontFamily="Manrope, sans-serif" fontSizes={[13,14,16,18,24,32,36]} fontWeight={500} sampleText="Menu margin · 76.2%" />

## Role scale

| Role | Minimum | Responsive maximum | Weight |
| --- | --- | --- | --- |
| Metadata, hint, badge, chart label | 13 px | 13 px | 400–600 |
| Body, control, table | 14 px | 16 px where needed | 400–600 |
| Section heading | 16 px | 18 px | 600–700 |
| Page heading | 24 px | 32 px | 600–700 |
| Headline metric | 28 px | 36 px | 500–600 |

Use rem-based bounds. The user can enlarge text; maximum role sizes are design defaults, not a limit on browser zoom or user preferences. Never shrink text to fit a container. Wrap, widen or simplify instead.

The 13 px minimum applies across both themes and every state, including helper text, errors, footnotes and labels. It is a Mise product requirement, not a WCAG minimum-font-size criterion. Validate resize and reflow under [WCAG 2.2](https://www.w3.org/TR/WCAG22/).
