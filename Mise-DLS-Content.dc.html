Content

Type, identity, numbers, and code. Numerals always render in General Sans Light with tabular figures so columns of money line up; prose is Manrope.

Heading

A titled break in the page. Level sets the semantic rank; size is chosen separately, so a subsection can look small without breaking the document outline.

{{ h.spec }} {{ h.sample }}
Props & accessibility level 1–6, required · size 'display' | 'xl' | 'lg' | 'md' | 'sm' | 'xs' · weight 700 | 800 · truncate boolean · as ElementType. Levels never skip — a page has one h1, and section titles descend in order regardless of visual size. Sentence case throughout; title case only in the product name.

Icon

A 24-grid line set drawn at 1.5px, rendered at 14, 16, or 20px. Icons support labels; they do not replace them outside toolbars and table rows.

Never scale an icon beyond 20px in the app; larger sizes belong to marketing illustration.

Timestamp

A formatted moment in the restaurant's timezone, not the browser's. Relative for recent activity, absolute everywhere money is involved.

{{ t.format }} {{ t.output }} {{ t.use }}
Props & accessibility value Date | ISO string · format 'relative' | 'time' | 'date' | 'datetime' | 'shift' · timezone string, defaults to the unit's · tooltip boolean, true — the absolute value on hover · refresh boolean for live relative values. Renders a <time> element with a machine-readable datetime; relative text is refreshed politely, never announced on every tick.

Token

A reference to a real entity inside a sentence or an input — a vendor, an invoice, an item. It carries an identity, so it can be removed as one unit rather than edited character by character.

inline in agent text Raised Romaine 24ct by 4 cases on PO-4471 for Harbor Produce.
removable · in an input
Cedar Dairy Harbor Produce Add a vendor…
Props & accessibility label string · entity { type, id } · tone 'reference' | 'neutral' · removable boolean · onRemove · onClick — opens the record in a HoverCard or navigates. Inside an input, tokens are list items with Backspace removing the last one, and the remove button carries "Remove Cedar Dairy".

Kbd

A keyboard key or a chord. Platform-aware: the same shortcut renders ⌘K on macOS and Ctrl K elsewhere.

⌘K CtrlK Esc ⏎
Props & accessibility keys string | string[] — 'mod+k' resolves per platform · tone 'default' | 'inverse' for dark surfaces · size 'sm' | 'md'. Renders <kbd> elements; symbol-only keys carry a spoken label so ⌘ is announced as "Command".

Code

Inline literal values — an ID, a field name, an API key fragment. In the app it appears mostly in integration settings and audit detail.

The webhook posts to /v1/invoices/matched with the header X-Mise-Unit. Props: children string · tone 'default' | 'danger' for invalid values · copyable boolean. Rendered as <code>; never used for emphasis.

Code Block

A multi-line sample with a language label and a copy action. Used in these docs and in the integrations area of the product.

Props & accessibility code string · language string · title string · copyable boolean, true · lineNumbers boolean, false · maxHeight number — scrolls beyond it · wrap boolean, true. The block is focusable and scrollable by keyboard; copy announces "Copied" through a polite live region, and the code itself is never the only place a value can be read.

Markdown

Renders agent output and vendor notes with the same type scale as the rest of the app. Lists, tables, inline code, and links only — no raw HTML, no images from untrusted text.

Why the order changed Romaine usage rose 18% against forecast. Two contributing factors:
Two catering covers on Thursday that were not in the forecast
Yield loss of about 9% on the last two Harbor cases
Case price moved from $23.00 to $29.10. See invoice INV-20841.
Props & safety content string · allow array of node types, defaults to headings, paragraphs, lists, tables, code, links, emphasis · maxHeadingLevel number, 3 — so agent output never outranks the page title · linkTarget · streaming boolean, which keeps partial nodes stable while text arrives. Raw HTML is stripped, not escaped and rendered.

Blockquote

Someone else's words, attributed. In the product it quotes a vendor note or an operator's comment; on marketing pages it carries a customer quote.

Short delivery on tomatoes was our error. Credit is approved for the crate.Marisol Vega · Harbor Produce · Aug 23
We stopped guessing at Friday close. The variance list is already waiting for us.Dana Mercer · Culinary Director, Fig & Oak
Props children ReactNode · attribution string · meta string · variant 'rule' | 'card' · size 'md' | 'lg' for marketing. Renders <blockquote> with the attribution in a <figcaption>; quotation marks are not drawn as decoration.

Citation

The record an agent claim came from. Every number the agent states in a decision context carries one, and clicking it opens the source.

Romaine ran 18% above forecast last week 1 and the case price rose twice this month 2.
1POS sales · week 34 2Invoice INV-20841
Props & accessibility index number · source { type, label, href, timestamp } · variant 'marker' | 'chip' · onOpen — opens the record in a panel rather than leaving the conversation. Markers are links with an accessible name of "Source 1, invoice INV-20841", not a bare number.
